# 시나리오 실증 자동화

플랫폼 접속부터 인증토큰 발급까지를 사람 대신 눌러 준다. 눈으로 볼 수 있게 실제 창을
띄우고 천천히 움직이며, 화면 아래에 지금 무엇을 하는지 자막을 띄운다.

```
플랫폼에서 공간 선택 → 확장으로 지갑 주소 가져오기 → 미보유 확인
  → 발급 요청 생성 → 확장이 지갑으로 전달 → 지갑 승인 창
  → 영지식 증명 생성 → Sepolia 온체인 발급
  → 플랫폼이 hasValidPass 로 확인 → 입장 가능
```

## 실행

```
npm run demo              # 지역청년패스
npm run demo:univ         # 지방거점국립대
npm run demo:check        # 준비 상태만 확인 (아무것도 켜지 않는다)
```

VSCode task `Demo (scenario run)` 도 같다.

**필요한 것은 알아서 켠다.** 검증자 웹과 데스크톱 지갑이 꺼져 있으면 시작하고, 이미 떠
있으면 그대로 쓴다. 켠 것은 끝나도 끄지 않는다 — 결과를 봐야 하고, 부모만 죽이면 Electron
자식이 파이프를 쥔 채 남는다.

브라우저는 자동화가 직접 띄운다(임시 프로필 + 확장 로드). 평소 쓰는 크롬은 건드리지 않는다.

## 한 번만 해 두면 되는 것

확장 빌드는 Node 22 가 필요해 자동화가 대신 하지 않는다.

```
nvm use 22.17.0
cd wallet/extension && pnpm build
cd wallet/desktop && yarn register:host      # 확장 ID 는 알아서 찾는다
```

## 화면 배치

녹화하기 좋게 창을 잡아 준다.

```
┌───────────────────┬───────────────────┐
│   ┌───────────┐   │                   │
│   │   지갑     │   │   비워 둔다        │
│   │ (정사각형)  │   │  (다른 작업용)      │
│   └───────────┘   │                   │
│    브라우저 (뒤)    │                   │
└───────────────────┴───────────────────┘
```

두 창 모두 한쪽 절반에 모아 둔다. 지갑은 그 절반 한가운데에 정사각형으로, 브라우저 위에
겹쳐 놓인다. 승인이 필요할 때 지갑이 앞으로 나오므로 흐름에는 문제가 없고, 녹화할 때
화면 한쪽만 잡으면 전 과정이 들어온다. 반대쪽 절반은 비워 둔다.

## 옵션

```
--scenario youth_pass|regional_national_univ
--slow 350        동작 간격(ms). 크게 하면 더 천천히 움직인다
--half left|right 두 창을 어느 쪽 절반에 모을지 (기본 left)
--full            창 배치를 하지 않고 최대화
--margin 28       지갑 창 여백
--keep            끝나고 브라우저를 닫지 않는다
--no-spawn        꺼진 것을 켜지 않고 실행 중인 것만 쓴다
--platform URL    기본 http://localhost:20260
--cdp 9222        지갑 CDP 포트
```

## 몇 번이든 돌릴 수 있다

`mintPass` 는 이미 보유 중이면 거부하지 않고 유효기간과 URI 를 갱신한다. 다만 두 번째
실행부터는 시작 상태가 이미 "입장 가능" 이라 발급 전후의 대비가 보이지 않는다.
그 대비까지 보여야 하면 아직 패스가 없는 다른 시나리오로 돌리면 된다.

## 실제 비용

Sepolia 에 진짜 트랜잭션을 보낸다. 실행마다 테스트넷 가스를 쓰고, 증명 생성과 확정에
수십 초가 걸린다. 발급 대기는 최대 4분까지 기다린다.

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 확장 ID 가 등록된 것과 다르다 | 안내되는 `yarn register:host <ID>` 를 실행 |
| 승인 창이 안 뜬다 | 지갑이 잠겨 있거나 요청에 맞는 증명서가 없다 |
| "지갑으로 바로 보내기" 가 없다 | 확장 미감지 — 빌드·등록 후 브라우저 재시작 |
| 지갑 창이 안 움직인다 | 앱이 옛 코드로 떠 있다. 다시 띄우면 적용된다 |
